Die Funktion regel

Du schreibst in Python die Funktion regel. Sie entscheidet für eine einzelne Zelle, ob diese in der nächsten Generation lebt. Das Programm ruft sie für jede Zelle im Grid auf.

def regel(lebendig, nachbarn):
    ...
    return True   # Zelle lebt
    return False  # Zelle ist tot
  • lebendig ist True, wenn die Zelle gerade lebt, sonst False.
  • nachbarn ist die Anzahl der lebenden Nachbarzellen – eine Zahl von 0 bis 8. Das Zählen übernimmt das Programm für dich.

Mit Regel übernehmen (oder Strg + Enter) wird deine Regel geprüft und aktiviert. Die Tabelle zeigt dir dann für jede mögliche Situation, was deine Regel entscheidet. Mit print(...) kannst du dir Werte in der Ausgabe anzeigen lassen.

Das Grid

  • Klicke auf Zellen, um sie lebendig oder tot zu machen. Du kannst auch mit gedrückter Maustaste zeichnen.
  • Schritt berechnet genau eine neue Generation, ⏮ geht einen Schritt zurück.
  • Reset stellt den Zustand von Generation 0 wieder her.
  • Nachbarzahlen zeigt in jeder Zelle, wie viele lebende Nachbarn sie hat.
  • Rand: umlaufend verbindet die Ränder: Wer rechts hinausläuft, kommt links wieder herein.
